Studio IA

Pour générer un visuel ou un texte, le nom du produit, les instructions et, selon le mode choisi, l'image fournie sont transmis à l'API du Studio. Cette API sollicite les services Meta et Baseten. Les crédits d'essai sont conservés dans le stockage local du navigateur.

Les photos et instructions que vous envoyez sont transmises à Meta (génération d'images) et à Baseten (rédaction de textes) uniquement pour produire le résultat demandé. Ces prestataires peuvent traiter les données hors de Côte d'Ivoire.

Votre solde de crédits du Studio est enregistré uniquement dans votre navigateur (stockage local) ; vous pouvez l'effacer à tout moment.
